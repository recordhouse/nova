
# 이미지 제작

## 1줄 프레임

* 배경: png 파일로 배경은 투명한 이미지로 제작.
* 전체 사이즈: 가로: 2500px, 세로 500px 제작.
* 프레임: 각 개인 프레임 사이즈는 가로 500px, 세로 500px
* 중요: 각 프레임끼리 서로 사이즈에 절대로 겹치지 않는다. 이미지끼리 간격 약간 벌려준다. 머리카락 뭉게지지않게 선명하게 표현한다.
* 포즈: 오른쪽 방향으로 80도 위를 발사하는 모습으로, 눈은 발사하는 방향으로 바라보고있다. 표정은 약간 찡그리고있다. 중간에 한프레임은 약간 눈을 감는다.
* 비율: 내가 첨부한 첫번째 이미지를 엄격하게 지키며, 캐릭터 사이즈는 똑같게 하여 프레임별 이질감이 없도록 한다.
* 추가 설명: 1줄로 만들고 한줄당 5프레임을 넣는다, 각 프레임마다 자연스럽게 행동이 이어지도록 한다.
* 추가 설명: 머리카락 디테일하게 뭉게지 않고 원본대로 작업한다.
* 추가 설명: 1프레임에서 5프레임으로 자연스럽게 표현하되 5프레임과 1프레임이 같은 이미지는 아니다.




## 2줄 프레임

* 전체 사이즈: 가로: 2500px, 세로 1000px 제작.

* 포즈: 점프한 상태에서 앞으로 양손을 향하여 총을 발사하는 모습.
* 비율: 내가 첨부한 첫번째 이미지를 엄격하게 지키며, 캐릭터 사이즈는 똑같게 하여 프레임별 이질감이 없도록 한다.

* 추가 설명: 머리카락 디테일하게 뭉게지 않고 원본대로 작업한다.
* 추가 설명: 1프레임에서 10프레임으로 자연스럽게 표현하되 10프레임과 1프레임이 같은 이미지는 아니다.
